# Agent's Brain (long-term memory)
- `~/brain` (an Obsidian vault) is your long-term memory, shared with the user's other coding agents; it replaces any built-in memory. Use the **brain** skill and the `brain` command.
- It is per project: `brain project` maps the current folder to `~/brain/Projects/<Name>/`; knowledge true in any repo lives in `~/brain/Global/`.
- Before non-trivial work, recall (`brain query "<topic>"` from the repo folder). Whenever you learn something durable (the user's corrections, decisions, gotchas, recipes, references), record it automatically following `~/brain/_meta/Conventions.md` and say in one line what you saved.
